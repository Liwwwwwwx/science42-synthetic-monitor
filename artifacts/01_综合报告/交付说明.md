## 使用方式


```powershell
npm install
npx playwright install chromium
npm run test:core-regression
npm run probe:team-api
npm run test:case-catalog
k6 run .\k6\site-smoke.js -e BASE_URL=http://192.168.0.112:23191 -e ITERATIONS=10
```
