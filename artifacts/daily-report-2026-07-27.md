## 三、今日发现的问题

### 问题一：严格输出约束不稳定

当问题要求“只输出整数”时，平台仍返回了计算过程；当问题要求“只输出代码词”时，平台返回了说明文字加代码词，说明当前结果判定不能只依据 HTTP 200 或页面出现文本，还必须增加 JSON、纯数字、固定行数和固定关键词等业务级校验。

### 问题二：回答内容串台或流式结果污染

在上一条严格 JSON 测试后立即执行三点列表测试时，平台返回了上一条 JSON 尾部残片，说明可能存在流式片段未清理、任务 ID/消息 ID 关联错误、前端状态复用、AbortController 未正确结束或消息列表 key 错位等问题，需要结合浏览器 Network 原始流、请求 ID 和服务端日志继续定位。

### 问题三：历史会话达到上限

聊天页面显示“最近对话 100/100”，导致新建会话类测试受到环境容量限制；后续需要为自动化测试准备专用账号、测试会话清理策略或由平台提供测试环境重置能力，不能让监控脚本未经确认直接删除已有业务会话。

### 问题四：登录态存在失效场景

自动化脚本曾捕获到页面提示“登录已过期，请重新登录”，并在截图中确认登录窗口、账号输入框和滑块验证均出现；这证明登录失效能够被发现，但还需要完善自动重新登录、告警和恢复状态记录。
